# План: Исправление данных после миграции сезонов

## Проблема

После запуска `0008_season_isolation.sql`:
1. **Два «Текущий сезон»** — миграция выполнилась дважды или ON CONFLICT не сработал
2. **Пропали standings** — PK constraint не применился из-за NULL в season_id
3. **Пилоты без команд** — team_id ссылки сломаны (команды не загружаются)

## Причина

Миграция `0008` не была атомарной — при ошибке PK данные остались в промежуточном состоянии. Кроме того, миграция `0006` уже создавала «Текущий сезон», а `0008` создавала ещё один.

## Решение

### Шаг 1: Очистка данных (выполнить в Supabase SQL Editor)

```sql
-- 1. Удалить дублирующие сезоны (оставить самый старый)
DELETE FROM public.seasons
WHERE id NOT IN (
  SELECT MIN(id)
  FROM public.seasons
  GROUP BY championship_id, name
);

-- 2. Удалить все сезоны и начать заново
DELETE FROM public.seasons;
DELETE FROM public.stages WHERE season_id IS NOT NULL;
DELETE FROM public.standings WHERE season_id IS NOT NULL;
UPDATE public.teams SET season_id = NULL;
UPDATE public.drivers SET season_id = NULL;
```

### Шаг 2: Исправленная миграция (0008 v2)

Новая версия миграции, которая:
- Не создаёт сезоны автоматически
- Только добавляет колонки season_id (nullable)
- Не трогает существующие данные

```sql
-- Добавить season_id в teams (nullable)
ALTER TABLE public.teams
  ADD COLUMN IF NOT EXISTS season_id uuid REFERENCES public.seasons(id) ON DELETE SET NULL;
CREATE INDEX IF NOT EXISTS teams_season_idx ON public.teams(season_id);

-- Добавить season_id в drivers (nullable)
ALTER TABLE public.drivers
  ADD COLUMN IF NOT EXISTS season_id uuid REFERENCES public.seasons(id) ON DELETE SET NULL;
CREATE INDEX IF NOT EXISTS drivers_season_idx ON public.drivers(season_id);

-- Добавить season_id в standings (nullable, БЕЗ изменения PK)
ALTER TABLE public.standings
  ADD COLUMN IF NOT EXISTS season_id uuid REFERENCES public.seasons(id) ON DELETE SET NULL;
CREATE INDEX IF NOT EXISTS standings_season_idx ON public.standings(season_id);
```

### Шаг 3: После очистки — создать сезон вручную

В панели управления чемпионатом → Сезоны → «Новый сезон». Это создаст сезон и скопирует команды/пилотов.
