# Plan: Finish Season Feature

## Approach
Add `finished_at` timestamp to seasons. When a season is finished: set `finished_at = now()`, `is_active = false`. When creating a new season, auto-finish the previous active one.

## Changes

### 1. SQL migration — `supabase/migrations/0021_season_finished_at.sql`
```sql
BEGIN;
DO $$ BEGIN
  ALTER TABLE seasons ADD COLUMN finished_at timestamptz;
EXCEPTION WHEN duplicate_column THEN NULL; END $$;
COMMIT;
```

### 2. Database types — `src/lib/database.types.ts`
Add `finished_at: string | null;` to `SeasonRow`.

### 3. Domain types — `src/types.ts`
Add `finishedAt: number | null;` to `Season` interface.

### 4. Mappers — `src/lib/api/mappers.ts`
- `rowToSeason`: add `finishedAt: r.finished_at ? new Date(r.finished_at).getTime() : null`

### 5. API — `src/lib/api/seasons.ts`
Add `finish(id)` function:
```typescript
export async function finish(id: string): Promise<void> {
  const { error } = await supabase
    .from('seasons')
    .update({ is_active: false, finished_at: new Date().toISOString() } as never)
    .eq('id', id);
  if (error) throw error;
}
```

Update `create` to auto-finish previous active season before creating new one:
```typescript
export async function create(championshipId: string, name: string): Promise<Season> {
  // Finish previous active season
  await supabase
    .from('seasons')
    .update({ is_active: false, finished_at: new Date().toISOString() } as never)
    .eq('championship_id', championshipId)
    .eq('is_active', true);

  const { data, error } = await supabase
    .from('seasons')
    .insert(seasonToInsert({ championshipId, name }) as never)
    .select('*')
    .single();
  if (error) throw error;
  return rowToSeason(data);
}
```
