# LMERC — Платформа спортивных онлайн таблиц для автоспорта

Создай полноценную интерактивную веб-платформу для управления чемпионатами
по автоспорту. Вдохновение — challenge.place, но с уникальным визуальным
стилем и глубокой функциональностью.

- **Didact Gothic** (Google Fonts) — основной шрифт интерфейса:

### Типографика
```
h1 (названия чемпионатов): Didact Gothic, 48–72px, letter-spacing: 2px
h2 (заголовки секций): Didact Gothic, 32px, letter-spacing: 1.5px
h3 (названия команд/пилотов): Didact Gothic, 18px, font-weight: 700
body: Didact Gothic, 14–16px, line-height: 1.6
table-data: Didact Gothic, 14px
numbers/stats: Didact Gothic, 14–16px
badges/tags: Didact Gothic, 11px, uppercase, letter-spacing: 1px
```

### Визуальный стиль
- Тёмная тема — единственная (без light mode)
- Акцент — lime вспышки на hover, активных состояниях
- Карточки с тонкой lime-обводкой при hover: border: 1px solid #C6FF00
- Таблицы: чередование строк #111 / #151515, hover → #1E1E1E
- Кнопки: lime bg + black text, sharp corners (border-radius: 4px)
- Иконки: Lucide React — минималистичный стиль
- Тонкие анимации: transition: all 0.2s ease на интерактивных элементах
- Drag-and-drop с lime-подсветкой зоны сброса
- Числа мест в таблице: Bebas Neue крупно, с lime-цветом для топ-3
- Золото/серебро/бронза только текстом или lime-градацией яркости

## АРХИТЕКТУРА И НАВИГАЦИЯ

### Структура страниц
```
/ (Landing)
  └── Список публичных чемпионатов
  └── Кнопка "Создать чемпионат" (только авторизованным)

/championship/:id (Публичная страница чемпионата)
  ├── Вкладка "Обзор" — описание, баннер, статистика
  ├── Вкладка "Пилоты" — таблица пилотов с очками
  ├── Вкладка "Команды" — таблица команд с очками
  ├── Вкладка "Участники" — список команд и пилотов
  └── Вкладка "Этапы" — история всех этапов

/championship/:id/manage (Панель организатора — приватная)
  ├── Настройки чемпионата
  ├── Управление командами и пилотами
  ├── Управление системой очков
  └── Проведение этапов
```

### Хранение данных (window.storage API)
- Shared storage (shared: true) — публичные данные: чемпионаты,
  таблицы, этапы, результаты
- Personal storage (shared: false) — приватные: токен организатора,
  черновики, настройки
- Ключи: `championship:{id}`, `standings:{id}`, `stage:{id}:{stageId}`,
  `teams:{id}`, `scoring:{id}`
- Организатор идентифицируется по уникальному токену (UUID),
  сохранённому в personal storage при создании чемпионата

## МОДУЛИ ФУНКЦИОНАЛЬНОСТИ

### 1. ЛЕНДИНГ И СПИСОК ЧЕМПИОНАТОВ
- Hero-секция: название LMERC крупно (Didact Gothic), подзаголовок,
  lime-кнопка "Создать чемпионат"
- Сетка карточек чемпионатов (grid, 3 колонки на desktop):
  - Баннер-изображение (16:9 или 21:9)
  - Название (Didact Gothic)
  - Краткое описание (Didact Gothic, 2 строки, ellipsis)
  - Количество команд, пилотов, этапов (Didact Gothic)
  - Статус: АКТИВЕН / ЗАВЕРШЁН (badge, lime или muted)
- Пустое состояние с призывом создать первый чемпионат

### 2. СОЗДАНИЕ ЧЕМПИОНАТА
**Форма в модальном окне или отдельной странице:**
- Название (обязательно)
- Слоган / подзаголовок
- Загрузка баннера (drag-and-drop зона или кнопка,
  preview сразу после загрузки, base64)
- Описание (textarea, min 3 строки)
- Дисциплина (выпадающий список: Formula 1, GT Racing,
  Rally, Karting, Custom...)
- Сезон / год
- После создания → генерация уникального ID и токена организатора,
  редирект на страницу управления

### 3. УПРАВЛЕНИЕ КОМАНДАМИ
**Страница /manage → вкладка "Команды":**
- Список существующих команд в виде карточек
- Каждая карточка:
  - Логотип команды (загружаемое фото или placeholder)
  - Название команды (Didact Gothic)
  - Основной цвет команды (color picker → цветная полоска слева)
  - Список пилотов команды (аватар + имя)
  - Кнопки: Редактировать / Удалить
- Кнопка "Добавить команду" → модальное окно:
  - Название
  - Загрузка логотипа
  - Выбор цвета команды
- Drag-and-drop пилотов между карточками команд
  (пилот захватывается, перетаскивается в другую команду)

### 4. УПРАВЛЕНИЕ ПИЛОТАМИ
**Внутри каждой команды:**
- Список пилотов с фото (аватар 40x40, круглый)
- Данные пилота: имя, фамилия, номер, национальность (emoji флаг)
- Кнопки: Редактировать / Удалить / Переместить в команду
- Модальное окно добавления/редактирования пилота:
  - Имя и фамилия
  - Гоночный номер (Roboto Mono, крупно)
  - Национальность (выпадающий список с флагами)
  - Фото (загрузка, preview, base64)
  - Команда (можно сменить отсюда)

### 5. СИСТЕМА НАЧИСЛЕНИЯ ОЧКОВ
**Вкладка "Система очков" в панели управления:**
- Таблица: Место → Очки
- Динамическое добавление строк (кнопка "+ Добавить место")
- Примеры пресетов (кнопки быстрого выбора):
  - Formula 1 (25-18-15-12-10-8-6-4-2-1)
  - Sprint (8-7-6-5-4-3-2-1)
  - Custom
- Инпуты для очков: Roboto Mono шрифт
- Бонусные очки (опционально): поул-позиция, быстрый круг
- Сохранение системы отдельно от этапов

### 6. ИНИЦИАЛИЗАЦИЯ ТАБЛИЦ
**Вкладка "Таблицы" → первоначальная настройка:**
- Список всех добавленных команд с чекбоксами
- Организатор выбирает команды-участники чемпионата
- Кнопка "Инициализировать чемпионат":
  - Создаются две таблицы с нулевыми очками
  - Таблица пилотов: все пилоты выбранных команд
  - Таблица команд: выбранные команды
  - После инициализации таблицы становятся публичными
- Нельзя инициализировать повторно без сброса

### 7. ПРОСМОТР ТАБЛИЦ (публичный)
**Дизайн таблицы пилотов:**
```
| №  | Пилот          | Команда       | Очки | Победы | Подиумы |
|----|----------------|---------------|------|--------|---------|
| 1  | 🖼 Фамилия Имя  | ▌ Команда A   | 187  |   4    |    7    |
| 2  | 🖼 Фамилия Имя  | ▌ Команда B   | 165  |   2    |    5    |
```
- Место: Didact Gothic, крупно, lime для топ-3
- Фото пилота: аватар 32x32, круглый
- Цветная полоска команды слева от названия команды
- Очки: Didact Gothic, жирный
- Победы и подиумы: автосчёт из истории этапов
- Анимация обновления при изменении позиции

**Дизайн таблицы команд:**
```
| №  | Команда        | Пилоты           | Очки |
|----|----------------|------------------|------|
| 1  | 🖼 Команда A   | Пилот 1, Пилот 2 | 352  |
```

### 8. ПРОВЕДЕНИЕ ЭТАПА
**Вкладка "Этапы" → "Новый этап":**

**Шаг 1 — Настройка этапа:**
- Название этапа (например: Гран-при России)
- Трасса / локация
- Дата проведения
- Тип: Гонка / Квалификация / Спринт
- Применяемая система очков (из созданных)

**Шаг 2 — Выбор участников:**
- Список всех зарегистрированных пилотов
- Чекбоксы выбора (кто едет в этом этапе)
- Кнопка "Выбрать всех" / "Снять выбор"
- Счётчик выбранных пилотов

**Шаг 3 — Расстановка по местам:**
- Drag-and-drop интерфейс:
  - Левая колонна: список выбранных пилотов (неупорядоченный)
  - Правая колонна: пронумерованные слоты мест (1, 2, 3...)
  - Пилот перетаскивается из левой в слот нужного места
  - Lime-подсветка слота при наведении
  - Аватар и имя пилота видны в слоте
  - Можно менять местами пилотов внутри правой колонны
- Предпросмотр очков в реальном времени справа от слота

**Шаг 4 — Подтверждение:**
- Сводная таблица: кто → место → очки
- Кнопка "Подтвердить результаты"
- После подтверждения:
  - Очки пилотов обновляются
  - Очки команд пересчитываются (сумма пилотов)
  - Таблицы пересортировываются
  - Этап попадает в историю
  - Нельзя редактировать (только отменить этап целиком)

### 9. ИСТОРИЯ ЭТАПОВ (публичная вкладка)
- Список всех прошедших этапов в виде карточек
- Каждая карточка: название, дата, тип, победитель
- Раскрываемые детали: полная таблица финиша этапа
- Визуализация топ-3: подиум с именами и очками

## ТЕХНИЧЕСКИЕ ТРЕБОВАНИЯ

### Стек
- React 18 + TypeScript
- Tailwind CSS (utility-first стили)
- Lucide React (иконки)
- @dnd-kit/core или react-beautiful-dnd (drag-and-drop)
- Google Fonts: Didact Gothic, Bebas Neue, Roboto Mono

### Хранилище
- window.storage API для персистентности
- shared: true — для публичных данных (чемпионаты, таблицы)
- shared: false — для приватных (токен организатора)
- Batch-сохранение связанных данных одним ключом

### UX детали
- Все формы с валидацией и inline-ошибками
- Loading состояния при сохранении данных
- Toast-уведомления (успех / ошибка) в нижнем углу
- Пустые состояния с иллюстративным текстом и CTA
- Confirm-диалог перед деструктивными действиями (удаление)
- Адаптивность: полная поддержка мобильных устройств
- Skeleton-загрузка при получении данных из storage
